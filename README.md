# Baba Luxury Cars

A premium pre-owned dealership website built with Vite, Three.js and GSAP: the homepage film, a collection page, a page for each car, and an admin portal where the dealership manages the stock (Supabase). See [the admin guide](docs/ADMIN.md).

The homepage: A showroom inspection film of the Mercedes-Benz GLS 580 leads into the white Featured Collection, then About Baba (the GLS 580 and a Land Rover Defender 110 drive in and away on a white stage), The Baba Standard, Sell or Exchange, and the footer.

Every public page shares one motion layer (`src/fx/`, see [Motion layer](#motion-layer)): a gold loupe pointer with magnetic actions, a lacquer panel between pages, word-by-word headline reveals, and a Baba key hanging from the footer's coachline.

## Run

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5174
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4174
```

`dist/` is the static production site. Asset paths assume hosting at the domain root.

## Reaching us, cookies and counting

- **The footer** (`partials/footer.html`, `src/fx/footer.js`): *Let’s find your car.* in gold with the keys hanging beside it and, under *Talk to us*, whether the showroom is open now; then four columns, filled from the contact details the admin may change (`forms.js`): *Visit* (the address, the hours, directions in Google Maps or Apple Maps), *Talk to us* (each line, set large like a price, and WhatsApp), *Explore* (the pages) and *Follow* (Instagram and YouTube). The last line has the privacy policy, the terms, cookie settings, **Admin** (the portal at `/admin/`, kept out of search) and Back to top.
- **The WhatsApp button** (`src/whatsapp.js`): a disc of brushed gold in the bottom-right corner of every public page (on the home page, once the loader has gone). It opens an ivory card, gilt-edged like the consultation card's back, with the dealership's lines (Buy a car, Sell your car, Customer support), each opening a WhatsApp chat with its own first message, and whether the showroom is open now (11 am to 8 pm IST). The lines are set in the admin (Settings → WhatsApp lines) or, until saved there, `whatsappLines` in `config.js`. Anything marked `data-wa-open` (the footer's WhatsApp icon, the menu's WhatsApp button) opens the card too.
- **Icons** (`src/icons.js`): one set of line icons (WhatsApp, phone, email, the showroom, its hours, Instagram, YouTube, directions) for the footer's details and its WhatsApp / Instagram / YouTube row, the mobile menu, the About page's lines, and the WhatsApp and call buttons on the pages.
- **Directions**: Google Maps and Apple Maps buttons open route planning to the showroom from where the visitor is (`directions` in `config.js`), in the footer, the mobile menu and the About page's visit section; the consultation page's showroom row opens Apple Maps on an iPhone or iPad and Google Maps elsewhere.
- **Cookies** (`src/consent.js`): an ivory card in the bottom-left corner on the first visit asks about analytics cookies; essential ones are always on. The answer is kept in the `baba_consent` cookie for six months; *Cookie settings* in the footer, and the privacy policy, open it again. Google Analytics 4 (Consent Mode) loads only if `analytics.ga4` in `config.js` holds a measurement ID *and* the visitor allows it; withdrawn, its cookies are removed. It is empty, so nothing loads.
- **Counting** (`src/track.js` → `api/track.js` → `public.events`): each page seen, each car looked at (once per visit), and each tap to call, WhatsApp, get directions or shortlist, counted without cookies and without anything that identifies the visitor: the page, the car, the kind of device, the site a visit came from (on its first page) and the city Vercel reads for the request. Search engines and link previews are not counted. Only the live site counts; local development, which reads the live database, and the admin preview do not. The admin's **Insights** page (`src/admin/insights.js`, `public.insights()`) shows visits, car views, WhatsApp taps, calls, enquiries and directions against the period before (7, 30 or 90 days), every day of the period, the most viewed cars with their interest (contacts for each hundred views), cars on sale few are looking at, and where visits come from, where visitors are, what they use and what they read. Each car's views also show in the Cars list and its editor.

**Turning counting on** needs the `events` table and the `insights()` function in the database once: run the updated `supabase/schema.sql` (`npm run db:schema`). Until then the site's counts are dropped silently and Insights says it is not switched on.

## Search

`src/seo.js` holds every page's title and description; `vite.config.js` sets them into each page's head at build time, with its canonical address on `https://www.babaluxurycar.com` (the bare babaluxurycar.com redirects there), Open Graph and Twitter previews (`public/brand/og-image.jpg`, 1200×630), `en-IN`, and structured data: the dealership as an `AutoDealer` (address, hours, each line, its founders Vinod Ahuja and Pawan Ahuja, its slogan, Instagram and YouTube) and the `WebSite` on the home page, a breadcrumb on each inner page, the sell page's questions as a `FAQPage`. A car's page sets its own title, description, canonical address, preview photograph and structured data when the car is known (a `Car`, with its price as an `Offer` while it is for sale, and its breadcrumb); showcase models are kept out of search. Every page links `public/favicon.ico` (16, 32 and 48 px, for search results and older browsers) beside `favicon.svg`, and `public/site.webmanifest` (icons at 192 and 512 px in `public/brand/`). What only the dealership can give goes in `searchEngines` in `src/config.js`, each left out while empty: the Google Search Console and Bing verification codes, the showroom's map pin, the founding year and other profiles (such as the Google Business Profile). `public/robots.txt` keeps crawlers out of the admin and `/api/`, and points to `/sitemap.xml`, which `vercel.json` sends to `api/sitemap.js`: the pages and every car, read from the database when asked, each car with its first photograph. `vercel.json` also sets security headers and long caching for the build's hashed files, and marks every page served from a `*.vercel.app` address `noindex`, so search engines index the site only at its own domain.

## Motion layer

The home page's loader (`index.html`, `src/main.js`) shows the logo with a light passing across its gold and a large counter rolling to the share of the showroom loaded; when the film is ready the logo eases forward and the loader fades.

On every public page (`setupFx()` in `src/fx/index.js`, from `main.js` and `setupPage()`):

- **The loupe** (`src/fx/cursor.js`): on fine pointers, a gold point with a ring a beat behind it. Over a link or button the ring opens; over anything that can be handled it fills with gold and names the gesture (`data-cursor`: *Drag* on the film while the car can be looked around and on the keys, *Turn* on the parked About cars, *Hold* on the night drive, *Drag* on the handover photographs). Actions (`.solid-button`, `.outline-button`, `.enquire-link`, `.consult-cta`, `.fleet-button`, `[data-magnetic]`) are magnetic, after React Bits' Magnet: they lean towards the pointer and spring back. The browser's own cursor returns over fields, in dialogs and in the lightbox.
- **Between pages** (`src/fx/transition.js`): a black panel wipes up over the page, its rising edge coachlined, the logo fading in on it; the next page opens as the panel wipes on upward. The panel is a clip, so the logo never moves, only fades, and it is held at the home loader's logo size and place, so arriving home hands over to the loader without a seam. The panel is in `partials/header.html`, laid out inline, with one line of script that keeps it closed from the first paint after a transition, so the new page never flashes. Only links to another page of the site; never new tabs, modified clicks or links within the page.
- **Headlines** (`src/fx/reveal.js`): `data-reveal="words"` sets each word rising out of its line (the footer's *Let's find your car.*, each word in brushed gold); `data-reveal="fade"` brings a line up.
- **The keys** (`src/key-lanyard.js`): a Baba key fob on a woven lanyard printed BABA LUXURY CARS, hanging from the footer's coachline beside the invitation, made after the key Baba hands over in its delivery photographs: a piano-black pebble with a gold waistline, the logo in gold leaf, a row of lock, unlock and boot buttons (relief and satin finish from painted bump and roughness maps), and a steel flip-key blade. It swings in when the footer arrives, sways a little in the air, can be caught and thrown, and a tap turns it over and presses its lock: the footer's coachline blinks twice, as a car's indicators do when it locks. The strap, clamp and physics are React Bits' Lanyard, ported; the canvas covers the footer but never takes the pointer (the footer's events are read, and only a press on the key is the key's), so it never covers the button or links beneath it. Loaded only as the footer nears.

**Across India** now runs over a night drive (`src/night-drive.js`, React Bits' Hyperspeed ported to plain three.js): a highway after dark as a long exposure sees it. Ruby tail lamps stream away on the left (India drives on the left), warm headlamps come the other way, sodium lamps in the logo's gold pass at the verges, and the wet road carries their reflection. On large screens the stage pins: the road opens out of a window into the whole screen and gathers speed as the page is scrolled, and once it fills the screen the figures roll in over it; pressing and holding anywhere on it drives faster. Phones see the road behind the title, unpinned. Reduced motion keeps the section black and still. React Bits' licence is in `NOTICE.md`, and its banner is kept in the built files (`vite.config.js`).

## The one-to-one

The home page's consultation band (`partials/consultation.html`, `src/consultation.js`, `src/consult-stage.js`, `src/consult.css`) is "1:1" cast in gold: each figure is the "1" of Newsreader 72pt Light (its outline read from the font by `tools/glyph.py` into `src/glyphs.js`), extruded and bevelled, polished champagne gold on its faces and a deeper gold on its sides; the colon is two gold spheres. It stands in the About page's dark studio (`src/studio-stage.js`), on black stone that reflects it as a fading copy under the floor, with a warm glow at the horizon. Large screens pin it: the title is set as the band arrives; the figures stand apart, turned away, each in its own beam, "You" and "Us" on the floor before them; they turn to the visitor and come together as a softbox crosses their faces; the colon rises and rings, gold ripples running across the floor, then glows, the beams go down and the room and a pool of light come up; beside them the offer, the three points and the button that books the call follow. Scrolling back plays it in reverse, and the sculpture leans a little towards a fine pointer. Phones see the sculpture above the words, playing as it crosses the screen. Reduced motion and WebGL failure set "1:1" in gold type.

The page (`/consultation/`: `consultation/index.html`, `src/consultation-page.js`, `src/consult-page.css`, with the round button from `consult.css`) carries one object: a calling card, black board with a gilt edge, an engraved frame, the crest and "1:1" in foil whose light follows a fine pointer. It is dealt onto a desk under a lamp as the page opens, lying askew. On large screens the scroll picks it up: it lifts, straightens and turns over in the air, and lays itself beside the booking form. It is one fixed element placed every frame between the desk's slot and the booking's (sticky) slot, so it is glued to one or the other except in flight. Its ivory back is the appointment: *For*, *On*, *At* (IST), *By* and *About*, each line written on as its answer changes. Making the request presses a gold seal into it, and the card keeps what was sent after the form clears. The form asks how to call (phone or WhatsApp), the day (the next seven, in Indian time; today closes at 7 pm, and with today chosen the windows already past close too), the time of day within the showroom's hours, name, phone, an optional budget and what the car is for; a gold plate glides to each choice. It goes through `forms.js` as a consultation request (a concierge enquiry in the admin, its day and time in the details). Then the questions, pinned on large screens: *We start with you, not a car.* steps up to its corner and each question rises, lights word by word as it is read and makes way for the next, ending on *Then, a shortlist.*; elsewhere they light in a column. Last, three ways to talk on paper (a phone call, WhatsApp, the showroom with its address and hours from the admin), each row inked in from the left under the pointer. Phones, tablets and reduced motion keep the card on the desk and a turned copy above the form.

## Sell your car

`/sell/` (`sell/index.html`, `src/sell-page.js`, `src/sell.css`) opens on the car's own number plate: an Indian high-security plate (retro-reflective sheeting, the raised black rim, the chakra hologram and IND in blue, two snap locks, the laser-etched number) standing on a lacquer floor that reflects it. The owner types the registration into it: each letter is pressed in as it arrives and the plate gives under it; empty, it shows an example in blind relief. *Start the appraisal* carries the number, grouped (`formatRegistration` in `valuation.js`), to the form. The buying team's line is `dealerLines` in `config.js`. Then:

- **From first look to handover**: an odometer of six real ten-sided drums (built in the page) whose last, white drum clicks over from 1 to 4 as the pinned scroll reads the four steps; the list lights the step it shows.
- **Sell it / Exchange it**: two doors, black and paper; the one under a fine pointer opens wider and its title grows with it. Each sets the form's exchange switch and goes to the form.
- **The appraisal**, on paper: the car (make and model, year, kilometres, city, registration, owners so far), its care (service history, both keys, warranty, insurance, accident-free) and the owner, beside the car's record, a black folio that fills in: the plate, the name, an odometer rolled to the kilometres (read in thousands or lakh), the facts, the care as gold-ticked pills, and *To sell* or *To exchange*. A valuation enquiry through `forms.js`, the care as one detail.
- **Questions owners ask**, opening one at a time, and a way to call the buying team or book a 1:1 call.

The page scrolls through Lenis on fine pointers (`src/smooth.js`, shared with the consultation page): native scrolling, eased, so sticky panels and the card's fixed flight work as written. Over the paper sections the header turns to paper (`paperHeader` in `chrome.js`). Nothing here states a price, a timeline or a payment term; those come from the dealership.

## The About page

`/about/` (`about/index.html`, `src/about-page.js`, `src/about-page.css`) is black lacquer throughout, scrolled through ScrollSmoother on desktop. Its words are the dealership's own (babaluxurycar.com: *Built on trust. Driven by quality.*, carefully selected, professionally evaluated and transparently presented, clear information on the RC, insurance, service history and ownership, finance through trusted partners, a relationship that does not end with the sale) and the figures in `config.js`; nothing else is claimed.

- **The unveiling** (`src/unveil.js`, `src/cloth.js`): a Mercedes-Maybach S 580 in a dark studio under an ivory satin cover, the Baba logo worked in gold thread on its bonnet, a gold band round its hem, lined in champagne. The cover is simulated: a grid of particles held by stretch constraints, softer shear, bend and curvature constraints (woven cloth gives on the bias and folds in broad, soft folds, never kinks), dropped over the car while the page loads and left to fall. The studio air is still: it resists the cloth across its face with the square of its speed (a sheet of satin falls flat at about 1.4 m/s), so it floats and billows, and hardly at all along it. The car is a height map rendered from above; cloth that sinks into it is lifted onto the surface, or moved out by the shorter way where it has swung into a side, without picking up any speed of its own, so it hangs down the doors without rattling against them. Friction is Coulomb's: a contact grips in proportion to how hard it is pressed, so the cover stays where it lies or slips off cleanly, never crawls. The pinned scroll is the hand on the middle of the back hem: it lifts it and draws the cover back over the roof and up out of sight, at a person's pace while the cover is on the car and quicker once it is clear. Held by its hem, the sheet is tethered (long-range attachments), so a hanging length cannot stretch and stops when the hand stops. The pull is filmed as it happens; scrolling back leads the cloth (still simulated) back through that film, so the cover comes back over the car and lies exactly as it lay. Once the cloth has stopped moving, the simulation and the drawing sleep until the scroll moves again. It is drawn with thickness, a face and a lining 7 mm apart joined round the hem, refined to twice the simulation's resolution with Catmull-Rom curves and shaded in the valleys of its folds. The face is satin: a five-harness weave as a normal map, its highlight drawn out along the warp (anisotropy), and a soft sheen at grazing angles. On larger screens the frame renders through 4× MSAA at half-float precision, then contrast-adaptive sharpening (after AMD FidelityFX CAS), and every texture on the car is filtered at the GPU's full anisotropy. A softbox runs nose to tail as the cover leaves. The floor is black stone polished to a soft mirror, more blurred with distance (from a mipmapped reflection, so a wide blur stays a smooth wash), meeting a cyclorama with one warm glow at the horizon. Phones get a wider lens, a smaller cloth, native antialiasing and no mirror. Reduced motion and WebGL failure show the still.
- **Section heads** (`.ab-mast`): kept to what they need. The title steps down in two lines (the second in gold italic, indented under the first), and one sentence hangs at the right on the title's last line. There is no eyebrow, number or section name. The lines rise out of their own, and the sentence comes up, as the head is reached.
- **Our story**: the manifesto at a reading size and measure, in the middle of the page, each word coming out of a soft blur as it is read (after React Bits' Scroll Reveal). Nothing else moves.
- **The founders**: *Two founders, one promise.* Vinod Ahuja and Pawan Ahuja, Vinod first, each in their own photograph (`public/founders/`), whole and at its own shape, side by side and stepped, with their names beneath; beside them how it began, more than eighteen years ago: their first sale, a Hyundai Santro listed online when few Delhi dealers did, sold on the promise that it was exactly as described; then a showroom in Paschim Vihar; today more than fifty luxury cars. The photographs are lifted into the light as they arrive and, on large screens, drift a little apart with the scroll; each paragraph's lines rise out of their own as it is reached, and a gold rule beside the story is drawn as it is read. Below 1000 px wide: the title, the photographs, then the story.
- **The figures** (`src/fascia.js`): *Never rolled back.* A pre-owned car is only as honest as its odometer, so Baba's own record is read off a rotating display set into a piano-black dashboard, after the three-sided display in Bentley's Continental GT and Flying Spur. The pinned scroll turns it, and each turn is the real mechanism's three linked motions: back into the dash for clearance, round, and forward into place, carried on a spring so it moves with weight and settles with a small detent. Its faces, in order: book-matched walnut (generated, figure and pores, mirrored at the seam) with the Baba crest inlaid in gold; three dials (a black sunburst face, gold applied indices with the scale's numerals outside them so the needle never crosses one, a hairline for the needle's sweep, a knurled chrome bezel, a domed lens; no minor marks and no crest), which go through a car's ignition as they arrive (they light, the needles sweep to the stop and back, then rise to the figures while the readouts count) and blip a needle under the pointer; and a navigation screen as the car's own would be: a status bar keeping New Delhi time, and a map drawn as a car's navigation draws one (`drawMap`): a city at night seen from behind and above the car, heading up, so the road under the car always runs up the screen and the whole map turns as the car takes a corner. Streets and avenues, parks and low buildings stand in perspective and fade into the dark with distance; the route is a lit gold band along the avenues with marks flowing along it; the car's mark is a folded arrowhead lying on the road, pointing the way the car is going, in the ring a position has; a banner gives the turn coming and how far off it is, and a compass turns with the map. The city is made up (a repeating grid the route steps through), not a real place, and beside it each place a car has gone to in turn (*Delivered to*), with its distance from the Delhi showroom, the part of the country it is in as that is said in India (North India, South India, the North-East…), a hairline lit as far as that is, and what they add up to in the country's own phrase (*From Kashmir to Kanyakumari.*). The clock is twelve-hour, marked IST. Distances are aerial (straight, to the centre of the state or to the city named), to the nearest ten kilometres, and the screen says so. No country, border or real road is drawn (states and common cities are known by name in `PLACES`; others, and New Delhi and its neighbours, are not shown). While it faces out the screen runs, painted some thirty times a second; turned away, off screen or in a hidden tab it is not painted at all. The figures come from `figures` in `src/config.js`, the places from the handover photographs (built in, and the admin's Deliveries). The cabin's ambient light traces round the opening as the section arrives. There is nothing under the display, no caption and no selector, so it has the height of the screen; the scroll alone turns it. The lacquer, chrome and glass reflect a black studio of strip softboxes placed outside the flat lacquer's mirror, so the dash stays black while every curve draws a line of light; the metals and walnut also see a warm bounce card, so gold reads as gold. Rendered on demand through 4× MSAA, a soft bloom and contrast-adaptive sharpening on large screens; resting, it draws nothing. On a portrait screen the display stands upright and turns like a revolving door. Reduced motion and WebGL failure show the figures as type.
- **The inspection** (`src/inspect-stage.js`): on paper, where the rest of the page is black (the header is set in ink while it is on screen). ## The collection drive

On a seamless white stage after the film (`src/fleet-drive.js`, `src/fleet-storyboard.js`), a Toyota Land Cruiser 300, a Land Rover Defender 110 (in Carpathian Grey with the Narvik Black roof, for this scene only), a Mercedes-Maybach S 580, the GLS 580 and the X7 set off line abreast out of the white and drive towards the visitor. The cars carry no names and open nothing: the picture is only a picture. The scroll is the only clock, so it reverses exactly. The stills stand in until the models arrive, and without WebGL.

The same drive opens the collection page (`mode: 'stage'`). There it runs on its own clock as the page opens, over 4.6 seconds. The cars park in a tighter V, seen from nearer their own roof height, so the group fills the width. A wall-high *COLLECTION* stands behind them, and the cars cover the lower part of its letters. The canvas is transparent: far away, the cars fade towards clear rather than towards white, so they never veil the title. Whatever height is left over is shared above the title and above the words beneath (`--stage-shift`). A fine pointer sways the camera a little, the title less and the dust more, by depth. As the page scrolls on, the title lags and pales. Reduced motion and WebGL failure show the stills (`*-fleet.webp` for the repainted cars, from `FLEET=1 npm run stills`) in the same arrangement; reduced motion downloads no models.

Dust is in the air on both stages: motes drift on slow currents behind and in front of the cars, brightening as they turn through the light (`src/dust.js`, two light 2D canvases, paused off screen). As the cars roll, their tyres throw a little dust back and out across the floor, which billows and settles (`src/road-dust.js`, in the WebGL scene, so the cars hide what is behind them).

The three new models came from the supplied files and are prepared by `npm run model:fleet` (`tools/prep-fleet.mjs`; the i7's FBX is converted by `tools/fbx-to-glb.py`, from `5309329.6476c45879370.rar` extracted to `source/i7/`). Each is scaled to its real length (5,469, 5,391 and 4,985 mm), turned nose forward, grounded, its wheels grouped to roll (the S-Class's tyres, modelled one per axle, are split by side), simplified (the Land Cruiser from 1.1 million triangles to 174,000; paint and glass keep nearly all theirs, since their double layers fold through each other when simplified coarsely) and compressed to 1.7–3.1 MB. The i7 wears matte Frozen Deep Grey; it is a showcase model in the collection and has its own page, but is no longer in the drive. The cars in the drive wear no plates.

The X7 M60i (`npm run model:x7m60`, the same script; it was the inspection's car before the Volvo and is no longer on a page; its model files are no longer in the repository, so the script needs `bmw_x7_m60i.glb` put back in the project root to run) arrived as a game-weight body: 44,000 triangles whose normals wander by degrees wherever the triangles run small or thin, so every panel lit, and above all reflected, as if dented. Its shape is left exactly as it is and its normals are faired (`tools/fair-surface.mjs`): long edges are halved until none is longer than 8 cm, each vertex takes a normal from the faces round it (one for each side of a crease, so panel edges and swage lines stay sharp), and each normal is then averaged, by area, with those within a few centimetres of it across the same panel. The averaging is over the surface, not the mesh, so it does not depend on how a panel happens to be cut up. Those normals are stored at 12 bits rather than the 8 the compressor would give them: on a surface that mirrors the studio, 8-bit normals show as a ragged edge on every reflection. The file is 2.2 MB.

## Experience

The film inspects one car: the Mercedes-Benz GLS 580 in Cavansite Blue. Its glazing follows the real GLS (X167): the windscreen and front door glass are clear, with the faint green-grey of heat-insulating glass, so the cabin reads; the rear door and quarter windows, tailgate glass and roof are dark privacy glass, standard on the GLS, and the rear doors' window-frame uprights are piano black, with chrome only on the window outline and beltline. Its engine bay is finished from photographs of a real GLS (satin charcoal covers, black ducts, a white coolant tank, a chrome star): `tools/cars/gls.mjs` splits the bay's materials from the exterior's. Its stars are as on the car: the grille's 3D star is chrome on a gloss black disc, the bonnet badge and wheel centre caps (blank discs in the source) each get a faceted chrome star and ring on gloss black enamel, built in `src/badges.js` and fitted to each disc (the wheel stars turn with their wheels), and the tailgate star, left in black trim by the source, is satin chrome; the piece the model preparation took for the tailgate badge is the rear wiper's pivot cap, now black. Its headlamps read through their glass: behind a clear lens the housing is dark graphite, the three MULTIBEAM reflector cells and bezels are chrome, the LED chips glow softly in their cells, the projector is dark optical glass, and the brow carries the daytime running light. All glass on the cars reflects at full strength over its tint, more at a glance than head-on (`src/glass.js`): three.js would otherwise scale reflections by opacity, so a clear lens all but vanished. After the engine and the open-door interior reveal, the camera pulls back, the door closes, and the car drives forward towards the front doorway. There are no 360° orbits, parked return loops, engine buttons or sound.

The film is set in the supplied car showroom (`car-showroom_2.glb`), prepared with `npm run model:showroom` into `public/models/showroom.glb`. It is a 26.3 m square room under a luminous ceiling grid, each panel a softly lit diffuser, glowing warm and brightest over the inspection stage. Its walls are fluted smoked oak, slat by slat a shade apart; light slots stand in the panel-seam reveals 5.32 m and 10.64 m from each wall's centre line, and an LED shadow-gap skirting runs along the floor. The floor is polished large-format stone in 1.33 m tiles on the walls' panel grid, with a flush turntable ringed by a warm LED line at the inspection mark, and a light strip crosses each threshold (`src/showroom-floor.js`). The doorways stand in bronze portals. The Baba logo is lit on the back wall, beside the drive-in doorway, for the whole film (`src/studio-environment.js`). The slots, skirting, ring and logo are all captured into the car's reflections, so the paint reflects clean studio light shapes; the grid between the ceiling panels reflects as a soft line, so the bodywork's ripples never wobble. Drive-in (rear) and drive-out (front) doorways are cut at existing wall-panel seams, and the front and rear walls bounce light only either side of them, so a car crossing a threshold is lit evenly. The film opens in the lit showroom with the GLS emerging through the rear doorway, and anything beyond the walls fades into darkness. The GLS's walkaround circles the car in one direction and covers less than a full turn: rear three-quarter, right flank, front wheel, bonnet, then the driver's door. The camera keeps moving between these points instead of stopping at each one. The camera then turns to follow the GLS out, and the film ends as it crosses the front threshold, tail lamps lit. The film keeps drawing while it scrolls away, so the scrub settles on that last frame.

The film speaks as a pre-owned luxury dealer in India would: what a buyer checks, chapter by chapter. Paint, repaints and accident history; tread depth, tyre age and brakes; the service book, odometer and RC; the cabin and a test drive; then exchange and paperwork. Headlines are light Newsreader: “Choosing well.”, “Honest bodywork.” and “Drive it home.” sit between the room and the car, so the bodywork passes in front of the words. The overlay is built to read over anything the film shows: each chapter's label is a pair of solid tags, and its note sits on a dark, gold-edged panel with the chapter's checks listed beneath it as tags (solid, never blurred over the moving stage). These titles drift gently with the scroll, reversing with it; the wheel, engine and cabin shots use smaller foreground headlines. Each line is rasterised into its own texture band, with correct display colour and device-pixel alignment. Broad, soft shading keeps the room behind the type quiet without darkening the car or surrounding every letter with a heavy shadow. Phone captions sit at the foot of the stage, clear of the moving subject. As the loader clears, the opening title rises into place. The chapter rail jumps through the film, and the DOM headings retain the accessible text and static fallback. The film's own links (*Browse the collection*, *Find your next car*, *Skip to collection*) open the collection page.

The white Featured Collection follows the film directly. About Baba comes next: a pinned white stage on which the BMW X7 (navy metallic) and the Land Rover Defender 110 drive in out of the white, stop side by side, and hold, then drive away out of frame. The Defender is dressed as a Fuji White car (Land Rover paint 867, a solid white) with the Narvik Black contrast roof: gloss black roof, pillars and DEFENDER lettering, Ceres Silver skid plates and bonnet vents, textured black arches, gloss dark grey wheels. The source also carries the Hard Top's body-coloured panels a millimetre outside the rear quarter glass; they are hidden, so the passenger 110's quarter windows show glass instead of flickering white slabs, and the About camera's near plane stands well out, so the depth buffer stays fine at its 22–27 m distance. The introduction is always set: a two-line headline whose second line turns in italic, in the logo's deep gold, with the introduction in the text face and a signature line beneath. The camera looks up the lanes as the cars appear and turns with them, so they arrive beside the copy (below it on phones), never behind it, and leave away from it. The scroll position is the only clock, so scrolling back replays it exactly. Desktop places the copy at left and the cars at right; phones and other tall screens stack the copy above the cars. ## Look

The film is tone mapped with Khronos PBR Neutral, which reproduces base colours one to one and compresses only the highlights, so the Cavansite Blue reads as itself rather than near-black.

The page uses a black-and-gold finish. The ground is true black paint (OLED phones render it as black), and soft grey gradients read as studio light reflected in it. Gold appears as a fine coachline. That line runs under the glass header and fills as you read down the page. It also edges the sections, the collection plinths, the forms and the dialogs. The brand is the client's own logo (`public/brand/`, from `source/blc-logo-transparent.png`, as published on babaluxurycar.com). It appears in the loader, header and footer, and on the number plates. ## Performance

The homepage film and lights-on collection keep the same render density while moving and at rest (`src/render-density.js`): native density up to 2×, with desktop supersampling towards 2× within a pixel budget. Sustained slowness can lower desktop supersampling once per measurement window, down to native density or 1.5×, whichever is higher; phones retain their target density. Car textures use anisotropic filtering. The hero retains MSAA throughout. The collection uses SMAA while scrolling and adds MSAA after settling; phones retain MSAA throughout. Its full HDR render target is released between still frames, and its reflection is reused on alternate moving frames. Geometry and model textures are unchanged.

The hero rehearses its inspection shots behind the loader. The collection loads one car at a time, uploads textures in batches, compiles shaders for its actual HDR target, and rehearses geometry in small batches before appearing. Background work yields around active scrolling (`src/idle.js`); About waits for the collection to load. Phones share their GPU memory among the page's stages, and iPhone Safari takes a WebGL context away when they run short (or when the visitor has left the tab a while), so on phones: the collection drive and About send their cars' textures at 512 px a side (`maxTexture` in `car.js`; the model files are untouched) and refract glass at half resolution, the collection drive multisamples twice rather than four times, and About is made only as it comes near. A stage whose context is lost shows its stills and is built again, on a fresh canvas and out of sight, the next time its section comes near (`revive` in `main.js`); the film losing its context once it has begun leaves only its own still in place (`film-lost`), and only a film that cannot start puts the whole page in its stills. Loading on phones: the film's own car downloads first and alone (the loader waits on it), the collection drive's cars after it; the collection page's five cars download at high priority from the first line of its script; on a phone the collection drive's background steps wait a quarter as long for the page to be still, and its warm-up no longer waits for complete stillness; About is made three screens ahead. The models, the studio light and the stills are cached for a day and refreshed in the background for a week (`vercel.json`). Scrolling on iPhone and iPad: pages with pinned stages (home, About) hand scrolling to ScrollTrigger (`steady-scroll.js`, `normalizeScroll`), since iOS Safari paints the scroll before a pin is set and pins otherwise jump; the collection drive has no scroll parallax on touch screens, no dust on phones, and the collection page's seals simply fade in, set, on phones and tablets (`hallmarks.js`). On a portrait screen the collection page's cars arrive from much nearer (from 0.4 of the drive, not out of the far white), so they fill the space under the title at once and park within two seconds, in an open V with white between the cars; on phones its stills (reduced motion, no WebGL) are set in the page's flow, title, cars over the foot of its letters, then the words, with no band of white between them. Area-light shading shares view and roughness calculations across lights and skips lights that are off (`src/area-lights.js`). Dust starts in a quiet moment, uses a smaller canvas, and pauses off screen. Hidden film captions no longer rewrite identical styles on every frame. See [homepage performance notes](docs/HOME-PERFORMANCE.md) for research, measurements and limits.

The showroom uses one ceiling area light, captured room reflections and a hemisphere fill. Its stone floor uses the captured environment and baked contact shadows instead of a planar mirror. Blurred glass is never layered over a moving 3D stage.

Every page's stylesheets are linked from its `<head>`, not imported by its script, so a page is never painted without them (in development Vite injects script-imported CSS only once the script has run, and the bare HTML showed for a moment). On the About page the hero's words arrive at once and are animated by the browser (the Web Animations API), so they come up smoothly while the stage behind them is built; the cover's settling runs a few steps to a frame; the figures' display is made only once the hero has loaded; and shaders are compiled ahead without holding the page (`src/compile.js`): where the browser cannot say when a program is ready (Firefox has no `KHR_parallel_shader_compile`), three's `compileAsync` returns at once and the first frame then waits on every program, so a fence is set behind the compile commands in the GPU's queue and watched instead. In Firefox the hero's words used to appear after about five seconds, with freezes of up to 1.6 s; they now start within half a second, and the longest freeze is about 0.4 s.

A car can be loaded whole and still open quickly (`src/detail-car.js`, `tools/prep-s90.mjs`; built for a Volvo S90 Recharge supplied as one 386 MB file of 3.3 million triangles and 45 textures, most of them 4K, and not on a page at present). Nothing is simplified. The geometry is packed with meshopt and split into body and cabin; each texture is written at 1K, 2K and 4K; the page shows the body with the 1K set (about 16 MB instead of 386), brings the cabin in behind it, and loads the larger textures only for what the camera is close to, since all 45 at 4K together would need over 3 GB of video memory. The supplied file is far over GitHub's 100 MB limit, is not part of the site and is not kept in the repository: `npm run model:s90 -- path/to/the.glb` prepares it from wherever it is.

`src/config.js` holds the dealership identity, fallback contact information, optional enquiry endpoint, the showcase models and fallback inventory. | `src/admin/` | The admin portal: `store.js` (Supabase or browser preview), `cars.js`, `photos.js`, `home.js`, `collections.js`, `settings.js` |
| `supabase/schema.sql` | Tables, row-level security, photo bucket and starting collections |
| `src/forms.js` | Enquiry and valuation handling |

The existing model preparation and inspection scripts remain in `tools/`. `docs/model-audit.json` (GLS 580, X7) and `docs/showroom-audit.json` record the supplied geometry. `npm run model:defender` prepares the Defender (`tools/prep-defender.mjs`: drops two stray badges 98 m away and the source plates, scales it to 5,018 mm, rigs the wheels on their axles, names its materials in English) and bakes its shadow (`tools/prep-studio.mjs` and `docs/studio-audit.json` belong to the previous studio, which the film no longer loads). The X7's bonnet remains closed because its source does not contain an engine. `npm run model:x7` keeps the X7's original baked interior (an earlier version re-toned it beige and brown).

Use Node 22+ with Vite and a local Chrome debugging session:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --remote-debugging-port=9222 --user-data-dir=/tmp/baba-browser-review --no-first-run about:blank
npm run check:browser
npm run check:browser -- --smoke --retina
npm run check:home -- http://127.0.0.1:5174
npm run check:home -- http://127.0.0.1:5174 --mobile
npm run stills
STILLS=gls npm run stills   # only the listed showcase IDs
```

The existing `FORMA_SITE_URL`, `FORMA_CDP_URL` and `FORMA_REVIEW_DIR` environment overrides remain compatible. Screenshots default to `/tmp/baba-review`. The checks never send enquiries to a configured endpoint.

`check:home` measures frame gaps through the first two sections and back, then checks collection readiness, scroll reversal, overflow and browser exceptions. Use Vite or an instrumented bundle (`NODE_ENV=development npx vite build --outDir /tmp/baba-perf`) for its scene hooks. `WAIT=600` starts scrolling soon after the loader, `--cold-network` disables the HTTP cache, and `BLC_PERF_REPORT=/tmp/home-performance.json` saves the report. Run screenshots separately from timing and avoid other GPU-heavy tabs.

Reduced motion skips the film and all GLB downloads. Loading failures, WebGL failure and context loss retain the practical site and vehicle stills. Local fonts and models avoid third-party runtime requests. Rendering stops when unchanged or hidden.
